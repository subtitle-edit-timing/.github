# Subtitle Edit - Lines That Match Your Video

## Departure

The video is a file you may caption: your own edit, a lecture you recorded, or a clip the owner asked you to subtitle.
You have a subtitle file already, or you are starting a new one for that video.
You can hear the line you are typing.
The subtitle file will sit next to the video with a name you will recognize.

## Weather

A caption that is early or late is a timing problem, not a font problem.
One paragraph of speech should not be a single endless line. Break it where a person can read it.
Auto-translation, if the build offers it, is a draft. Read it. Do not ship a language you cannot check.
If the video has no dialogue, you do not need a subtitle track full of guesses.

## Fuel

Open the video.
Open or create the subtitle file.
Fix one line that is wrong, or add the first line at the moment you hear it.
Save, then play that moment in a normal player with the subtitle file beside the video, if the player loads external captions.

## Heading

The line appears when the person speaks.
It leaves before the next sentence piles on top.
The spelling is the spelling you intended.
The video file's date did not need to change for this save.

![Subtitle Edit with one caption lined up to speech in a video the user owns](https://whatsoftware.com/wp-content/uploads/2008/01/Jubler-subtitle-editor.png)

## Cruise

Continue line by line. Do not restyle the whole file before the words are right.
Save often. A subtitle file is small. Losing an hour of timing is not.
Keep the previous version of the subtitle file if you are about to run a global time shift.
A global shift is one number, then you check the start, the middle, and the end.

## Diversion

The captions are all late after a shift. Undo the shift or apply the opposite number. Do not nudge fifty lines by hand until you know the offset.
The player does not show the file. It may want the subtitle next to the video with a matching name, or you loaded the wrong video.
The waveform is empty. The video's audio track may be missing. Fix the video in the editor that made it, not by inventing times.
You wanted subtitles for a commercial disc you do not have the right to copy. Stop.

## Approach

Name the file with the language and the video name.
Keep a copy before you send it to someone else.
Subtitle Edit can close. The text file is the work.
If you burn captions into the picture, that is a new video export in another tool. Do that only when an external file is not acceptable, and keep the external file too.

## Landing

File saved.
One minute rechecked in a player.
No unfinished line left at a time you did not listen to.
The video original untouched.

## Not this flight

This is not a ripper.
It is not a translator you can trust without reading.
It is not a place to grab a subtitle from a site and call it yours.
A player plays the video. This edits the text.
Someone else's private video does not become yours because you can type on it.

## Next leg

The next video starts with a blank file or a copy of the style, not a copy of the old words.
After an update, open one known pair and check that a line still hits the speech.
A time shift you liked goes in the note as a number, not as a feeling.
New videos stay in the same folder as their caption files.

## Logbook

Video name.
Language.
Whether you shifted the whole file, and by how much.
Where the subtitle file lives.

## Tower

You are captioning material you may caption.
Do not publish a transcript of a conversation that was not yours to share.
A work file stays on the work machine if that was the rule.
Uninstall leaves the text files. They are ordinary documents after you save them.
